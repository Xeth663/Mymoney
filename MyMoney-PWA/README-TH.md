# MyMoney PWA — คู่มือภาษาไทย

แอปบันทึกรายรับรายจ่ายธีมดำ-เทา ออกแบบให้ใช้งานบนมือถือและติดตั้งเป็นไอคอนบนหน้าจอโฮม iPhone ได้ ข้อมูลรายการ/งบประมาณ/เป้าหมายเก็บในเบราว์เซอร์ของอุปกรณ์ (IndexedDB และ localStorage เป็นทางสำรอง) ไม่มีระบบบัญชีหรือ cloud sync

## ฟีเจอร์
- เพิ่ม/แก้ไข/ลบรายการรายรับและรายจ่าย
- พิมพ์ข้อความ เช่น “ข้าวกลางวัน 65 บาท” เพื่อช่วยเติมรายละเอียดและจำนวนเงิน
- บันทึกเสียงภาษาไทยผ่าน Web Speech API เมื่อเบราว์เซอร์รองรับและได้รับอนุญาตไมโครโฟน
- อ่านสลิปจากภาพด้วย OCR (Tesseract.js โหลดจาก CDN ต้องใช้อินเทอร์เน็ตครั้งแรก; ผลลัพธ์อาจผิด ต้องตรวจสอบก่อนบันทึก)
- สรุปรายรับ รายจ่าย ยอดสุทธิของเดือน และกราฟ
- ตั้งงบรายเดือนและเป้าหมายการออม
- ค้นหา/แก้ไข/ลบรายการย้อนหลัง
- ส่งออก CSV ที่เปิดใน Excel/Numbers ได้ และ JSON สำหรับสำรองข้อมูล
- ธีมดำ-เทาและสลับเป็นโหมดสว่าง
- PWA manifest, service worker, ไอคอน iPhone และแคชสำหรับเปิดแบบออฟไลน์หลังเข้าเว็บครั้งแรก

## วิธีโฮสต์ฟรีด้วย iPhone
1. แตก ZIP ด้วยแอป Files (แตะไฟล์ ZIP) ให้ได้โฟลเดอร์ `MyMoney-PWA` ซึ่งมี `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` และโฟลเดอร์ `icons`
2. เปิด Safari ไปที่ https://app.netlify.com/drop หรือใช้ GitHub + Netlify หากหน้า Drop ไม่รองรับการอัปโหลด ZIP โดยตรง ให้แตก ZIP ก่อนและอัปโหลดโฟลเดอร์/ไฟล์ตามวิธีที่บริการรองรับ
3. ถ้าใช้ GitHub: สร้าง repository ใหม่ → Add file / Upload files → อัปโหลดไฟล์ทั้งหมดจากโฟลเดอร์ (อย่าอัปโหลด ZIP แทนไฟล์โปรเจกต์) → Commit changes → เชื่อม repo กับ Netlify/Vercel หรือเปิด GitHub Pages
4. หลัง Deploy สำเร็จ ให้เปิด URL HTTPS ที่ได้ด้วย Safari บน iPhone
5. แตะปุ่ม Share (สี่เหลี่ยมมีลูกศรขึ้น) → Add to Home Screen → เปิด “Open as Web App” ถ้ามี → Add
6. เปิดจากไอคอน MyMoney แล้วเพิ่มรายการทดสอบ ตรวจสอบว่ารีเฟรชแล้วรายการยังอยู่ และดาวน์โหลด JSON สำรองไว้

## ข้อควรรู้สำคัญ
- **ข้อมูลอยู่ในอุปกรณ์และเบราว์เซอร์นั้นเท่านั้น** ไม่ซิงก์ข้ามเครื่อง ไม่สำรองอัตโนมัติ และอาจหายเมื่อลบข้อมูลเว็บไซต์/เปลี่ยนเครื่อง/ล้างเบราว์เซอร์
- ดาวน์โหลด JSON สำรองเป็นระยะ และเก็บไว้ในที่ปลอดภัย การนำเข้าไฟล์สำรองยังไม่ได้ทำเป็นปุ่มในรุ่นนี้
- CSV เป็นไฟล์ข้อความที่ Excel/Numbers เปิดได้ ไม่ใช่ไฟล์ `.xlsx` ดั้งเดิม
- OCR ต้องโหลด Tesseract.js จาก CDN และภาษา OCR; ต้องมีอินเทอร์เน็ต และไม่รับประกันความถูกต้องของยอดเงิน
- การบันทึกเสียงขึ้นกับการรองรับ Web Speech API ของเบราว์เซอร์/ระบบปฏิบัติการและการอนุญาตไมโครโฟน บางเบราว์เซอร์อาจไม่รองรับ
- แอปนี้ไม่เชื่อมธนาคาร ไม่ได้เข้ารหัสข้อมูลด้วยรหัสผ่าน และไม่ใช่เครื่องมือบัญชีที่ผ่านการรับรอง โปรดสำรองข้อมูลและตรวจสอบยอดเอง
- โฮสต์เว็บสาธารณะหมายถึงใครก็เปิดหน้าแอปได้ แต่รายการการเงินจะเก็บในเบราว์เซอร์ของแต่ละคน ไม่ส่งขึ้นโฮสต์

## การทดสอบ
เปิดผ่าน HTTPS หรือ localhost เพื่อให้ service worker ทำงาน การเปิด `index.html` โดยตรงจะไม่เปิดใช้ service worker
